# Journal

One file per entry: `YYYY-MM-DD.md`. Append-only — don't edit old entries except to
fix a factual error. If a day has a big update later, add a new entry, don't rewrite
history.

Loose structure, use what applies:

```markdown
# YYYY-MM-DD

## Numbers
Leads in / calls booked / proposals sent / closed / MRR from qviks upsells — whatever
moved.

## What happened
Free text. Decisions made, conversations had, what got shipped.

## Blockers
What's stuck and why.

## Next
1-3 concrete next actions.
```

Skip sections that don't apply that day. The point is a record we can both scan later
to see what actually moved the needle, not a complete diary.
