# The Ten Commandments of a Landing Page

House rules for every landing page drafted in this repo.

1. **Research first, design second** — gather everything findable about the
   subject before a single line of markup is written.
2. **Keep the research** — dump it in `draft/<name>/` as plain markdown, with
   sources, so the next person can check every claim.
3. **Never invent a fact** — no made-up dates, prices, quotes or credentials;
   mark anything unconfirmed as unverified and say so on the page.
4. **One page, one promise** — minimal, essential information and a few honest
   photos; cut anything the visitor does not need in order to decide.
5. **Lead with whatever is next** — the page surfaces the upcoming events on its
   own, and still reads well on the day there are none.
6. **Feed it, never hardcode it** — every event, date and editable word lives in
   one content file shaped like the QVIKS event feed, so the client edits data
   and the markup never has to change.
7. **Follow the house style** — every draft lives at `/draft/<name>`, images in
   `public/draft/<name>/`, noindex on, and it gets listed in `/draft/list`.
8. **Mark it a draft** — a visible demo badge, forms switched off, and a credit
   line back to the author until the client says go.
9. **Type with discipline** — display serif only above 30px, all small text and
   all digits in the sans.
10. **Ship it working** — responsive from 360px up, accessible, fast, and built
    and looked at before it is called done.
