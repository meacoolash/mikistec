# Notes

Undated, running lists — unlike the journal, these get edited in place as thinking
changes. Split into files by topic as they grow, e.g.:

- `offer-and-pricing.md` — packaging/pricing ideas and what's been tried
- `outreach.md` — channels tried, scripts, objections heard and how they were handled
- `qviks-upsell.md` — how the mikistec → qviks handoff is pitched, what's worked

Start a file the first time a topic needs one rather than pre-creating empty ones.
